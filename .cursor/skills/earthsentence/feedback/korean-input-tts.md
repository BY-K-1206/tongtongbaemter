# Feedback: 한국어 입력 / TTS / 자동재생

- 등록 시 영어/한국어 모드. 한국어면 등록 때 영문 번역 캐시 → 학습 시 재번역 최소화.
- **한→영 지문 수정**: 한글(`rawText`)과 학습용 영어(`cachedSentences`)를 한 화면에 함께 보여 줌. 영어 직접 수정 가능. 한글을 고친 뒤에는 「한글 기준으로 다시 번역」버튼으로 영어 박스를 갱신한 뒤 저장.
- 학습 Step 1: 영문 + 한국어 해석. Step 2+: 해석 숨김.
- TTS: Web Speech API. 문장 옆 「다시 듣기」배지로 수동 재생. **자동 재생** 토글 존중. (Space는 단어 칸 이동 전용)
- Listen & Type: 문장 표시 숨기고 오디오 중심 입력.
- 번역 API 실패 시 사용자에게 안내. 기본 MyMemory; 환경설정에서 Claude/OpenAI/OpenAI 호환으로 전환 가능.
